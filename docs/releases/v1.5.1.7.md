## 1.5.1.6 からの変更

実機で縦組みを読んでいて出てきた2件です。

### 全角の引用符 ＂＇ が回転しなかった

縦組みで `＂`(U+FF02) と `＇`(U+FF07) が横向きのまま残っていました。`FF00-FFEF`（全角形）を一括で「立てる」と判定していて、回す側の一覧に入っていなかったためです。1.5.1.5 で `＜＞` を直したのと同じ取りこぼしでした。

確認用 EPUB の2章に引用符を並べ、シミュレータで撮って墨の形で判定しました。回っていれば線が縦に積まれ、立っていれば横に並びます。

| 文字 | 修正前 | |
|---|---|---|
| `“ ”` U+201C/201D | 縦に積む | 回っていた |
| `" '` U+0022/0027 | 縦に積む | 回っていた |
| `〝 〟` U+301D/301F | 右上 / 左下 | 縦組み専用字形、正しい |
| **`＂ ＇` U+FF02/FF07** | **横に並ぶ** | **立ったまま** |

修正後、`＂` は縦2本（列の中央）から横2本の縦積み（列の右端）に変わっています。

`“” ‘’` と ASCII の `"'` はもともと寝かせる側に落ちていて、問題はありませんでした。全角形では他に `／＼｜＊＋` あたりも同じ理由で立ったままですが、今回は引用符だけにしています。

### 両端のボタン同時押しでフロントライトを切り替えられるようにした

**左端と右端のページ送りボタンを同時に押すと、明かりが点いたり消えたりします。**

これまで明かりの出し入れは、電源ボタンのダブルクリックか、画面上端からの下スワイプだけでした。前者は寝かせる操作と隣り合っていて押し間違えやすく、後者は本を持ち替えないと指が届きません。読書中に指が載っているのは両端のボタンなので、そこから届くようにしました。

スクリーンショット（電源 + 右端）と同じ仕組みで、組み合わせが成立している間は他の操作に渡しません。

**ひとつ制限があります。** 側面ボタンは既定で「押し下げ」でページを送るので、**先に触れた側の1回はそのままページが送られます**。人間の同時押しには数十ミリ秒のずれがあり、その間にページ送りが走ってしまうためです。これを消すにはすべてのページ送りに待ち時間を入れることになり、読書用途では割に合わないと判断しました。

**設定 → 読書 → 側面ボタンの長押し** を有効にしていると側面ボタンは「離し」で送るようになり、この場合はページは動きません。気になる場合はこちらにしてください。

## 確認の状況

**この版はシミュレータで確認したもので、実機での確認はまだです。**

- 引用符の回転は、シミュレータの画素で修正前後を比べて確認しました
- **ボタン同時押しは実機でしか確かめられません。** 押し心地と、上に書いた「1ページ送られる」がどのくらい気になるかは、実際に押してみてください

1.5.1.6 までに実機確認済みの項目には触れていません。変更は上記2箇所だけです。

## 既知の制限

- **両端ボタン同時押しは、既定の設定では先に触れた側で1ページ送られます**（上記）
- **小文字主体の欧文が、列の中でわずかに左へ寄って見えます。** 大文字とベースラインを揃えた結果で、小文字はインクがベースライン寄りに偏るためです。横組みで小文字が行の下側に寄るのと同じ現象です。数字と大文字は中心に来ます
- 全角形のうち `／＼｜＊＋` は縦組みで立ったままです
- 画像や表を含む本は縦組みで崩れます。組版を「幅と高さを入れ替えた紙面」で行っているためで、受け入れた判断です
- バイオニックリーディングは縦組みでは無効です。太字にする範囲を語頭から43%で決める仕組みで、分かち書きをしない日本語では前提が成り立ちません
- 背景反転は縦組みでも出ませんが、これは横組みでも同じです
- 脚注プレビューや抜き書き選択など、`renderContents()` を通らない描画経路は横組みのままです
- **配信フォントには矢印・幾何学図形・星・単位記号・囲み数字・罫線素片が入っていません。** 置換字形（◆）になります。詳細と対処は [日本語フォントで出せる文字と、変換側での対応方針](../japanese-font-coverage.md) に

## 入れ方

> [!IMPORTANT]
> **アプリ領域は2面あります。** どちらを起動するかは `otadata` が決めます。SDカードや OTA で更新した端末は `app1` から起動していることがあり、その状態で `0x10000`（app0）へ書いても**画面は何も変わりません**。両面へ書けば、どちらが選ばれても新しいファームが起動します。

```
py -m esptool --chip esp32s3 --port COM8 --baud 921600 write-flash 0x10000 CrossDiTo-x4-pro-v1.5.1.7.bin 0x7f0000 CrossDiTo-x4-pro-v1.5.1.7.bin
```

SDカード経由なら、`.bin` を SD に置いて 設定 → 本体 → SD Card Firmware Update から選びます。

**1.5.1.6 が入っている端末は OTA で更新できます。** 設定 → 本体 → 更新を確認。

書き込む前にハッシュを照合してください。

```
certutil -hashfile CrossDiTo-x4-pro-v1.5.1.7.bin SHA256
```

### 起動しなくなったら

**電源ボタン＋下ボタンを押しながら起動**すると、SDカードからのファーム更新画面だけが立ち上がります。正常な `.bin` を SD に置いておけばここから戻せます。

## 使い方

1. 設定 → フォントを管理 から `BIZUDGothic` などをダウンロードする（Wi-Fi 接続が必要）
2. 本文フォントにそのフォントを選ぶ
3. 設定 → 言語 で「日本語」を選ぶ。ここで縦書きにするか尋ねられます
4. あとから変えるなら 設定 → 読書 → ページレイアウト → 組み方向

記号が ◆ になるのが気になる場合は、自分で `.cpfont` を焼けば出せます。手順は [フォント生成CLIの仕様](../prompts/build-jp-font-cli.md) に、実際に通したコマンドごと書いてあります。

## 扱わないもの

青空文庫連携と TXT から EPUB への変換は、このファームウェアでは扱いません。読むものの用意は母艦側の仕事として切り分けています。
