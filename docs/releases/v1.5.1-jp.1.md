# CrossDiTo 1.5.1-jp.1

CrossDiTo_jp は [CrossDiTo 1.5.1](https://github.com/dito94/CrossDiTo) に日本語の読書環境を足した個人用のフォークです。CrossDiTo 1.5.1 そのものが [CrossInk 1.5.0](https://github.com/uxjulia/CrossInk) から作られた Xteink X4 Pro 向けのテストビルドで、さらにその元は [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) です。基盤のファームウェアと、そこから受け継いだ機能の功績はすべて上流の貢献者にあります。以下に挙げるのは、CrossDiTo 1.5.1 の上に足した変更だけです。

> [!WARNING]
> **実機未検証です。** シミュレータの画面でしか確認していません。表示・SDカード・入力・フロントライトのいずれも実機では動かしていません。書き込む前に、必ずフラッシュ全体のバックアップを取ってください（手順は下記）。

## この版に入っていないもの

公開後に受けたコードレビュー（Copilot）の指摘のうち、次の2件はこの版には入っていません。
次のプレリリース（jp.2）で入ります。

- `.cpfont` の vert セクション読み込みで、件数とビットマップの確保量をファイルの言い値に
  頼っていた点。壊れたファイルや細工されたファイルで範囲外を読みうる
- 縦組みの描画経路で寝かせ区間ごとに `std::string` を作っていた点（ヒープ断片化）

どちらも**正常な .cpfont を使う通常の読書では影響しません**。配布元の日本語フォントを
使うぶんには、この版で実機の確認を始めて差し支えありません。

## このリリースに入っているもの

| 追加 | 内容 |
|---|---|
| 日本語UI | 774キー中 765キーを翻訳。設定 → 言語 で「日本語」を選ぶ |
| 日本語フォント | `.cpfont v5` を受け付けるようにし、BIZ UDGothic / BIZ UD明朝 / NotoSansJP / NotoSerifJP を取得できるようにした |
| 縦組み | 段組みの流し込み、句読点・かぎ括弧の縦用字形、欧文の90°回転、小書き仮名の変位 |
| ルビ | 親文字の右に、半分の大きさで振る |
| 文字装飾 | 傍線は列の左（日本語の傍線の慣習どおり）、打ち消し線は列の中央、ガイドドットは語間 |
| 右綴じ | 縦組みではタップとスワイプのページ送り方向を裏返し、進捗バーを右端から左へ伸ばす |
| 行間・字間 | 行間（70〜200%）が列の間隔として効く。字間は縦組み用に0〜30%を新設 |
| 同梱言語の削減 | 英語＋日本語のみを焼く。文字列データが 422,112 B → 37,178 B |

縦組みの組版は「幅と高さを入れ替えた紙面」で横組みとして行い、配置の瞬間に画面座標へ戻しています。既存のレイアウトエンジン（`ChapterHtmlSlimParser` の49か所の高さ計算）に手を入れずに済ませるための方式です。この方式のおかげで、横組みで「字の上」に取るものが列の右、「字の下」に引くものが列の左に来るため、ルビと傍線の位置は座標を写すだけで日本語の慣習に一致しました。

実装の詳細は [docs/japanese.md](../japanese.md) を参照してください。

## あわせて直したもの

- **UIの日本語が全部豆腐（◆）になっていた。** UIの内蔵フォントはラテン専用で、日本語は同じ大きさのSDフォントへ回送されますが、その字形が載っていませんでした。本文は走査パスで先読みしているのに、UIには同じ仕掛けがありませんでした。
- **縦組みの本文が読めなかった。** 字送りを字形表から取っていたため、SDフォントの遅延ロードでまだ載っていない字が送り0になり、十数文字が同じ座標に積み上がっていました。
- **ルビ同士が重なっていた。** `drawText()` は上付き・下付きを半分の大きさで描くのに、`drawTextVertical()` は等倍で描いていました。
- **Windows でビルドが始まらなかった。** `core.autocrlf=true` でパッチが CRLF になり、ビルド前スクリプトの `git apply` が落ちていました。

## 入れ方

書き込むのはアプリケーションイメージだけです。ブートローダとパーティションテーブルは含みません。

### 書き込む前に: フラッシュ全体をバックアップ

**純正ファームから初めて入れる場合は必須です。** 純正のパーティション配置がこのファームと同じである保証はなく、アプリ領域だけ差し替えて起動しない可能性があります。

```
py -m esptool --chip esp32s3 --port COM5 --baud 921600 read_flash 0 0x1000000 stock-x4pro-backup.bin
```

戻すときは `write_flash 0 stock-x4pro-backup.bin` です。

### 方法A: SDカード経由

すでに CrossDiTo / CrossInk が入っている端末向けで、USB を使わないぶん安全です。

1. `.bin` を SDカードの任意の場所へ置く
2. 設定 → システム → SD Card Firmware Update から選んで確定

### 方法B: USB（esptool）

```
py -m pip install esptool
py -m esptool --chip esp32s3 --port COM5 --baud 921600 write_flash 0x10000 CrossDiTo-x4-pro-v1.5.1-jp.1.bin
```

`0x10000` は `partitions.csv` の `app0` の先頭です。

### 起動しなくなったら

**電源ボタン＋下ボタンを押しながら起動**すると、SDカードからのファーム更新画面だけが立ち上がります。正常な `.bin` を SD に置いておけばここから戻せます。X4 Pro が下ボタンを使うのは、上ボタンが GPIO0（ESP32-S3 のストラップピン）で起動時に誤検出しうるためです。

### 書き込む前にハッシュを照合する

リリースページに表示されるサイズと、手元で計算したハッシュを突き合わせてください。

```
certutil -hashfile CrossDiTo-x4-pro-v1.5.1-jp.1.bin SHA256
```

## 使い方

1. 設定 → フォントを管理 から `BIZUDGothic` などをダウンロードする
2. 本文フォントにそのフォントを選ぶ（UIの日本語もこのフォントから出ます）
3. 設定 → 言語 で「日本語」を選ぶ
4. 縦組みにするなら 設定 → 読書 → 組み方向 を「縦書き」にする

## 既知の制限

- **実機未検証。** 電子ペーパーの実描画、SDカードのI/O速度、タッチの実挙動はシミュレータでは再現していません。
- 画像や表を含む本は縦組みで崩れます。組版を「幅と高さを入れ替えた紙面」で行っているためで、受け入れた判断です。設定画面にも注記があります。
- バイオニックリーディングは縦組みでは無効です。組版が語を「太字の頭」と「残り」に割って測り、その合計で語の位置を決めるので、欧文を寝かせて描く縦組みでは位置がずれます。共通の測定コードに縦組みを通せば直せますが、横組みの組版を壊す危険に対して見返りが小さいと判断しました。
- 背景反転は縦組みでも出ませんが、これは横組みでも同じです。実文字への `background-color` はもともと描かれません。
- 脚注プレビューや抜き書き選択など、`renderContents()` を通らない描画経路は横組みのままです。
- 行間を詰めすぎると列が重なります。ただし同じ値では横組みでも行が重なるので、縦組み固有の破綻ではありません。実用域は 100% 以上です。
- 日本語フォントの配信は [zrn-ns/crosspoint-jp](https://github.com/zrn-ns/crosspoint-jp) のリリース資産に依存しています。常用するなら自前にミラーしてください。
- 日付書式のサンプル表示は英語のままです。実際の描画も英語の月名を出すため、ラベルだけ和訳すると表示と食い違います。

## 扱わないもの

青空文庫連携と TXT→EPUB 変換は、このファームウェアでは扱いません。端末側に持たせると、ネットワーク・スクレイピング・文字コード変換・組版前処理が読書アプリの中に混ざります。読むものの用意は母艦側の仕事として切り分けています。

なろう・カクヨムの作品を Xteink 向けの EPUB / XTC へ変換するものとして [NovelToXteink](https://github.com/simeon052/NovelToXteink) があります。

## 検証について

CI（build / cppcheck / clang-format ＋ シミュレータのスクリーンショット撮影）は全通過しています。シミュレータを headless で走らせて実際に描かれた画面を撮り、次を確認しました。

- 縦組み本文が読めること。列は右から左、句読点・かぎ括弧は縦用字形、欧文は90°回転、禁則も効く
- ルビが親文字の右に半分の大きさで振られ、列からはみ出さないこと
- 傍線は列の左、打ち消し線は列の中央、ガイドドットは語間に出ること
- UI が全画面で日本語になること（設定・リーダーメニュー・フロントライトパネル・ホーム）
- 右綴じのページ送りと、右端から左へ伸びる進捗バー
- 行間 70〜200% が列の間隔として効くこと

**ビルドが通ることと、実機で動くことは別です。** 上流の 1.5.1 が受けている実機での書き戻し検証は、このリリースでは行っていません。
