# CrossDiTo 1.5.1.5（日本語版 jp.5）

CrossDiTo_jp は [CrossDiTo 1.5.1](https://github.com/dito94/CrossDiTo) に日本語の読書環境を足した個人用のフォークです。CrossDiTo 1.5.1 そのものが [CrossInk 1.5.0](https://github.com/uxjulia/CrossInk) から作られた Xteink X4 Pro 向けのテストビルドで、さらにその元は [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) です。基盤のファームウェアと、そこから受け継いだ機能の功績はすべて上流の貢献者にあります。以下に挙げるのは、CrossDiTo 1.5.1 の上に足した変更だけです。

## 1.5.1.4 からの変更

実機で縦組みを通して読み、見つかったものを直しました。

### クラッシュを直した

**ファイル転送から「ネットワークに参加」を選ぶと落ちていました。**

コアダンプを読んだところ、EXCCAUSE 65（スタック末尾のウォッチポイント発火）で、落ちたのは画面描画のタスクでした。ネットワーク起動は無線のためにヒープを空ける目的で描画スタックを 8KB に絞っています。そこへ後述の CJK フォールバックを載せたため、日本語を描くたびに SD から字形を読み込む深い呼び出しが走り、8KB を超えました。

フォールバックを載せる起動では、本文を読むときと同じ 16KB を与えるようにしました。

### ネットワーク画面の日本語が豆腐だった

Wi-Fi・OTA・フォント管理・KOReader・OPDS の画面で、日本語が全部 ◆ になっていました。原因は2つありました。

**最小構成のネットワーク起動が SD フォントを丸ごと飛ばしていた。** 本文フォントを読まないのは妥当ですが、UI の CJK フォールバックまで落ちていました。本文フォントは読まずに UI に要る 8/10/12pt だけを載せるようにしました。

**Wi-Fi 選択画面が入る瞬間にフォントを落としていた。** スキャンに向けてヒープを空けるためですが、フォールバックも道連れでした。本文フォントだけを落として UI 用は残すようにしています。Web サーバ・KOReader・フォント取得も同じ経路を通るので、まとめて直っています。

### 縦組みの組版

| 直したもの | 内容 |
|---|---|
| 横罫が横線のまま残る | `<hr>` が組版座標のまま描かれていた。縦組みでは**縦罫**になる |
| ＜＞ が回転しない | 全角や CJK の範囲に入る括弧は無条件に立つ判定になっており、フォントが縦用字形を持たないと横向きのまま残っていた |
| 波線 〜 が回転しない | U+301C が回転一覧から漏れていた。同じ穴を機械的に洗い、8字を追加（〜〰゠－＝＿｟｠） |
| 寝かせた欧文の位置 | 字の外枠の中心を文字セルの中心に合わせるようにした |

括弧類は、フォントが縦用字形を持たない場合に**寝かせて縦向きに見せる**ようにしました。立てたまま残すより見た目が合います。、。！？ のように位置がずれるだけの文字は対象外です。

### 行間の導線

縦組みでは行間が「列と列の間隔」になりますが、設定はフォント設定の下にあり、字間はページレイアウトにありました。列の間隔を探してもページレイアウトには無い、という状態でした。

**縦組みのときだけ、ページレイアウトにも行間を出します。** 同じ設定なので、どちらから変えても同じ値が動きます。横組みのときは出しません。

あわせて、**縦書きに切り替えたとき行間が既定の 100% のままなら 120% に上げます。** 実機で 100% は列が接して見え、120% がちょうど良いという確認が取れました。好みではなく組み方の違いから来るものです。横組みは行の高さに ascender と descender ぶんの余白が含まれますが、縦組みでは行の高さが列の幅になり、漢字と仮名は字面が em いっぱいに広がるので余白が残りません。100% 以外にしてある値は動かしません。

## 既知の制限

- **小文字主体の欧文が、列の中でわずかに左へ寄って見えます。** 字の外枠の中心はセルの中心に合っていますが、小文字はインクがベースライン寄りに偏るためです。横組みで小文字が行の下側に寄るのと同じ現象で、外枠を基準にする限り避けられません。数字と大文字は中心に来ます
- 画像や表を含む本は縦組みで崩れます。組版を「幅と高さを入れ替えた紙面」で行っているためで、受け入れた判断です
- バイオニックリーディングは縦組みでは無効です。太字にする範囲を語頭から43%で決める仕組みで、分かち書きをしない日本語では前提が成り立ちません
- 背景反転は縦組みでも出ませんが、これは横組みでも同じです
- 脚注プレビューや抜き書き選択など、`renderContents()` を通らない描画経路は横組みのままです
- **配信フォントには矢印・幾何学図形・星・単位記号・囲み数字・罫線素片が入っていません。** 置換字形（◆）になります。詳細と対処は [日本語フォントで出せる文字と、変換側での対応方針](../japanese-font-coverage.md) に

## 入れ方

> [!IMPORTANT]
> **アプリ領域は2面あります。** どちらを起動するかは `otadata` が決めます。SDカードや OTA で更新した端末は `app1` から起動していることがあり、その状態で `0x10000`（app0）へ書いても**画面は何も変わりません**。両面へ書けば、どちらが選ばれても新しいファームが起動します。

```
py -m esptool --chip esp32s3 --port COM8 --baud 921600 write-flash 0x10000 CrossDiTo-x4-pro-v1.5.1.5.bin 0x7f0000 CrossDiTo-x4-pro-v1.5.1.5.bin
```

SDカード経由なら、`.bin` を SD に置いて 設定 → 本体 → SD Card Firmware Update から選びます。

**1.5.1.4 が入っている端末は OTA で更新できます。** 設定 → 本体 → 更新を確認。

書き込む前にハッシュを照合してください。

```
certutil -hashfile CrossDiTo-x4-pro-v1.5.1.5.bin SHA256
```

### 起動しなくなったら

**電源ボタン＋下ボタンを押しながら起動**すると、SDカードからのファーム更新画面だけが立ち上がります。正常な `.bin` を SD に置いておけばここから戻せます。

## 使い方

1. 設定 → フォントを管理 から `BIZUDGothic` などをダウンロードする（Wi-Fi 接続が必要）
2. 本文フォントにそのフォントを選ぶ
3. 設定 → 言語 で「日本語」を選ぶ。ここで縦書きにするか尋ねられます
4. あとから変えるなら 設定 → 読書 → ページレイアウト → 組み方向

記号が ◆ になるのが気になる場合は、自分で `.cpfont` を焼けば出せます。手順は [フォント生成CLIの仕様](../prompts/build-jp-font-cli.md) に、実際に通したコマンドごと書いてあります。

## 扱わないもの

青空文庫連携と TXT から EPUB への変換は、このファームウェアでは扱いません。読むものの用意は母艦側の仕事として切り分けています。

なろう・カクヨムの作品を Xteink 向けの EPUB / XTC へ変換するものとして [NovelToXteink](https://github.com/simeon052/NovelToXteink) があります。
