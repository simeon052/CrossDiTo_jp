# CrossDiTo 1.5.1.8（日本語版 jp.8）

CrossDiTo_jp は [CrossDiTo 1.5.1](https://github.com/dito94/CrossDiTo) に日本語の読書環境を足した個人用のフォークです。CrossDiTo 1.5.1 そのものが [CrossInk 1.5.0](https://github.com/uxjulia/CrossInk) から作られた Xteink X4 Pro 向けのテストビルドで、さらにその元は [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) です。基盤のファームウェアと、そこから受け継いだ機能の功績はすべて上流の貢献者にあります。以下に挙げるのは、CrossDiTo 1.5.1 の上に足した変更だけです。

## ファイル

- サイズ: 5,804,848 バイト
- SHA-256: `60bb31c2dd94bd113308ac550910443602255759f6460972fad7fc2b9993de1b`
- 対象コミット: `f951bc9`（main）

書き込む前に照合してください。手順は下記「入れ方」に。

## 1.5.1.7 からの変更

1.5.1.7 で「既知の制限」に書いた、**両端ボタン同時押しで1ページ送られてしまう**件を直しました。

### 側面ボタンのページ送りが「離し」になりました

**押した瞬間ではなく、指を離した瞬間にページが送られます。**

1.5.1.7 で入れた「両端のボタン同時押しでフロントライトを切り替える」は、先に触れた側が必ず1ページ送ってしまう状態でした。側面ボタンが押し下げの瞬間にページを送るので、人の同時押しにある数十ミリ秒のずれの間に送りが走ってしまうためです。

押し下げのまま消すには、すべてのページ送りに「もう片方が来るか」を待つ時間（60〜80ミリ秒）を入れることになり、読書用途では割に合いません。離しに揃えれば、組み合わせが成立している間に両方の縁を食えるのでページは動きません。

これは**長押し動作を設定したときにもともと通っている経路と同じ**で、新しい仕組みではありません。

結果：

- 片方だけ押して離す → これまでどおりページが送られる（送られる瞬間が、押した時から離した時に変わります）
- **両端を同時に押す → 明かりが切り替わり、ページは動きません**

### 同時押しの取りこぼしも直しました

同時押しの処理で、両方のボタンが離れた周回の扱いが間違っていて、**2つ目の離しの縁がページ送りとして通り抜けていました**。1.5.1.7 では押し下げで送っていたため表に出ていませんでしたが、上の変更を入れると効いてきます。

## 確認の状況

実機（Xteink X4 Pro）で確認済み。1.5.1.7 の挙動と比べて、こちらのほうが良いという判断でこの版にしています。

## 既知の制限

- **小文字主体の欧文が、列の中でわずかに左へ寄って見えます。** 大文字とベースラインを揃えた結果で、小文字はインクがベースライン寄りに偏るためです。横組みで小文字が行の下側に寄るのと同じ現象です。数字と大文字は中心に来ます
- 全角形のうち `／＼｜＊＋` は縦組みで立ったままです
- 画像や表を含む本は縦組みで崩れます。組版を「幅と高さを入れ替えた紙面」で行っているためで、受け入れた判断です
- バイオニックリーディングは縦組みでは無効です。太字にする範囲を語頭から43%で決める仕組みで、分かち書きをしない日本語では前提が成り立ちません
- 背景反転は縦組みでも出ませんが、これは横組みでも同じです
- 脚注プレビューや抜き書き選択など、`renderContents()` を通らない描画経路は横組みのままです
- **配信フォントには矢印・幾何学図形・星・単位記号・囲み数字・罫線素片が入っていません。** 置換字形（◆）になります。詳細と対処は [日本語フォントで出せる文字と、変換側での対応方針](../japanese-font-coverage.md) に

## 入れ方

> [!IMPORTANT]
> **アプリ領域は2面あります。** どちらを起動するかは `otadata` が決めます。SDカードや OTA で更新した端末は `app1` から起動していることがあり、その状態で `0x10000`（app0）へ書いても**画面は何も変わりません**。両面へ書けば、どちらが選ばれても新しいファームが起動します。

```
py -m esptool --chip esp32s3 --port COM8 --baud 921600 write-flash 0x10000 CrossDiTo-x4-pro-v1.5.1.8.bin 0x7f0000 CrossDiTo-x4-pro-v1.5.1.8.bin
```

SDカード経由なら、`.bin` を SD に置いて 設定 → 本体 → SD Card Firmware Update から選びます。

**1.5.1.7 が入っている端末は OTA で更新できます。** 設定 → 本体 → 更新を確認。

書き込む前にハッシュを照合してください。

```
certutil -hashfile CrossDiTo-x4-pro-v1.5.1.8.bin SHA256
```

### 起動しなくなったら

**電源ボタン＋下ボタンを押しながら起動**すると、SDカードからのファーム更新画面だけが立ち上がります。正常な `.bin` を SD に置いておけばここから戻せます。

## 使い方

1. 設定 → フォントを管理 から `BIZUDGothic` などをダウンロードする（Wi-Fi 接続が必要）
2. 本文フォントにそのフォントを選ぶ
3. 設定 → 言語 で「日本語」を選ぶ。ここで縦書きにするか尋ねられます
4. あとから変えるなら 設定 → 読書 → ページレイアウト → 組み方向

記号が ◆ になるのが気になる場合は、自分で `.cpfont` を焼けば出せます。手順は [フォント生成CLIの仕様](../prompts/build-jp-font-cli.md) に、実際に通したコマンドごと書いてあります。

## 扱わないもの

青空文庫連携と TXT から EPUB への変換は、このファームウェアでは扱いません。読むものの用意は母艦側の仕事として切り分けています。

なろう・カクヨムの作品を Xteink 向けの EPUB / XTC へ変換するものとして [NovelToXteink](https://github.com/simeon052/NovelToXteink) があります。
