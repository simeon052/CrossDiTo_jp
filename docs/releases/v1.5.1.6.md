# CrossDiTo 1.5.1.6（日本語版 jp.6）

CrossDiTo_jp は [CrossDiTo 1.5.1](https://github.com/dito94/CrossDiTo) に日本語の読書環境を足した個人用のフォークです。CrossDiTo 1.5.1 そのものが [CrossInk 1.5.0](https://github.com/uxjulia/CrossInk) から作られた Xteink X4 Pro 向けのテストビルドで、さらにその元は [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) です。基盤のファームウェアと、そこから受け継いだ機能の功績はすべて上流の貢献者にあります。以下に挙げるのは、CrossDiTo 1.5.1 の上に足した変更だけです。

## 1.5.1.5 からの変更

縦組みのずれを1件だけ直した版です。

### 寝かせた欧文が列の中心から左へずれるのを直した

1.5.1.5 の「既知の制限」に書いた「小文字主体の欧文がわずかに左へ寄る」は、**小文字だけの話ではありませんでした。数字も大文字も 5px 左へずれていて、しかもページによって出たり消えたりします。**

原因は組版ではなく、セル幅の測り方でした。寝かせた欧文を全角文字と同じ軸に載せるために、全角1文字ぶんのセル幅を「あ」(U+3042) を測って決めていました。ところがSDフォントの送り幅は**そのページに出てくる字ぶんしか載りません**。本文に「あ」が無いページでは測れず、置換字形の幅が返ります。

シミュレータに値を吐かせたところ、正しい全角送り 29 に対して 20 が返っていました。中心合わせの量が `(29-1)/2 - 13 = +1` ではなく `(20-1)/2 - 13 = -4` になり、差の 5px がそのまま欧文のずれになります。ページに「あ」があるかどうかで症状が変わるため、実機の写真では条件が掴めず、何度も往復していた不具合です。

ページの内容に依存しない値から取るようにしました。行の中に立つ全角文字があればその送り幅を、無ければフォントの行送りを使います。

確認用 EPUB をシミュレータで撮り、画素で測った結果（同じ列の全角文字の軸との差）:

| 列の内容 | 修正前 | 修正後 |
|---|---|---|
| `100点満点中5000点…` | -4.5px | **-1.0px** |
| `CrossDiTo は ESP32-S3 で動く` | -4.5px（小文字 -8.0px） | **-3.0px**（小文字のみ） |
| `Flash は 88.4% を使っている` | -4.5px | **-0.5px** |
| 見出し `1 欧文と数字の向き` | -4.5px | **-0.5px** |
| 欧文を含まない列 | -0.5px 以内 | 変化なし |

残る -3.0px は小文字だけに出るもので、大文字とベースラインを揃えた結果です。横組みで小文字が行の下側に寄るのと同じで、外枠を基準にする限り避けられません。

### 確認の仕掛け

数pxのずれを写真で詰めるのは無理があったので、**同じ本・同じ設定をシミュレータに読ませて PNG を持ち帰る**ワークフロー（`verify-screenshots`）と、修正点が並んだ確認用 EPUB（`test/epubs/verify_japanese_vertical.epub`）を入れてあります。手で起動して、EPUB・設定・ページ送りの回数を指定して撮ります。今回のずれはこれで確定させました。

## 確認の状況

**この版はシミュレータで画素を測って確認したもので、実機での確認はまだです。** 上の表がその測定結果です。1.5.1.5 で実機確認済みの項目（クラッシュ、ネットワーク画面の日本語、罫線、括弧の回転、ルビ、字間、OTA）には触っていません。変更は `GfxRenderer::drawTextVertical` のセル幅の求め方 1 箇所だけです。

## 既知の制限

- **小文字主体の欧文が、列の中でわずかに左へ寄って見えます。** 大文字とベースラインを揃えた結果で、小文字はインクがベースライン寄りに偏るためです。横組みで小文字が行の下側に寄るのと同じ現象です。数字と大文字は中心に来ます
- 画像や表を含む本は縦組みで崩れます。組版を「幅と高さを入れ替えた紙面」で行っているためで、受け入れた判断です
- バイオニックリーディングは縦組みでは無効です。太字にする範囲を語頭から43%で決める仕組みで、分かち書きをしない日本語では前提が成り立ちません
- 背景反転は縦組みでも出ませんが、これは横組みでも同じです
- 脚注プレビューや抜き書き選択など、`renderContents()` を通らない描画経路は横組みのままです
- **配信フォントには矢印・幾何学図形・星・単位記号・囲み数字・罫線素片が入っていません。** 置換字形（◆）になります。詳細と対処は [日本語フォントで出せる文字と、変換側での対応方針](../japanese-font-coverage.md) に

## 入れ方

> [!IMPORTANT]
> **アプリ領域は2面あります。** どちらを起動するかは `otadata` が決めます。SDカードや OTA で更新した端末は `app1` から起動していることがあり、その状態で `0x10000`（app0）へ書いても**画面は何も変わりません**。両面へ書けば、どちらが選ばれても新しいファームが起動します。

```
py -m esptool --chip esp32s3 --port COM8 --baud 921600 write-flash 0x10000 CrossDiTo-x4-pro-v1.5.1.6.bin 0x7f0000 CrossDiTo-x4-pro-v1.5.1.6.bin
```

SDカード経由なら、`.bin` を SD に置いて 設定 → 本体 → SD Card Firmware Update から選びます。

**1.5.1.5 が入っている端末は OTA で更新できます。** 設定 → 本体 → 更新を確認。

書き込む前にハッシュを照合してください。

```
certutil -hashfile CrossDiTo-x4-pro-v1.5.1.6.bin SHA256
```

### 起動しなくなったら

**電源ボタン＋下ボタンを押しながら起動**すると、SDカードからのファーム更新画面だけが立ち上がります。正常な `.bin` を SD に置いておけばここから戻せます。

## 使い方

1. 設定 → フォントを管理 から `BIZUDGothic` などをダウンロードする（Wi-Fi 接続が必要）
2. 本文フォントにそのフォントを選ぶ
3. 設定 → 言語 で「日本語」を選ぶ。ここで縦書きにするか尋ねられます
4. あとから変えるなら 設定 → 読書 → ページレイアウト → 組み方向

記号が ◆ になるのが気になる場合は、自分で `.cpfont` を焼けば出せます。手順は [フォント生成CLIの仕様](../prompts/build-jp-font-cli.md) に、実際に通したコマンドごと書いてあります。

## 扱わないもの

青空文庫連携と TXT から EPUB への変換は、このファームウェアでは扱いません。読むものの用意は母艦側の仕事として切り分けています。

なろう・カクヨムの作品を Xteink 向けの EPUB / XTC へ変換するものとして [NovelToXteink](https://github.com/simeon052/NovelToXteink) があります。
